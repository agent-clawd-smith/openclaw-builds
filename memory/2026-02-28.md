## Lessons Learned

- Chrome extension relay struggles with complex SPAs (Google Cloud Console, Apple ID) — JavaScript clicks often redirect to google.com. Navigate via URL where possible.
- iCloud calendar sharing to Gmail doesn't sync — need CalDAV directly
- Apple app-specific passwords needed for CalDAV (not main password)
- gog CLI needs OAuth client credentials before auth flow
- openhue uses color names not hex codes
